# Depth

Do the task with the tools, methods, and raw material a top person in the field would use.

## Sub-features

- instruments: the same tools the best people use.
- unreasonable-goal: a specific hard target, treated as solvable.
- raw-check: reproduce a belief from raw material.
- new-knowledge: a blind spot that predicts on material it was not fit to.
- outside-judge: a grader that is not the worker.

## How to get to it (user POV)

- A first task, `/deepstack-mode`, or the depth playbook.
- The user wants the task done at an expert level, at the same size.

## Driving it with the DeepStack skills

Preconditions: a task, and any hard constraints copied as their own lines.

- Write the three lines in [intake](../intake.md). Result: scope, examples, and blocker are present before a plan.
- Answer the four questions in your own sentences. Result: each answer is a todo item, and the same session does the work.

## Gotchas

- Pasting the question sentences into the plan adds words and no answers.
- A scope line that contains an example noun needs a named blocker.
- A markdown table where the field uses a database is a wording change.

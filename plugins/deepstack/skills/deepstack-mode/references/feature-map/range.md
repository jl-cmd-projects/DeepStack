# Range

Bring in fields the surface task does not name.

## Sub-features

- verbs: replace each noun with the action it hides.
- crew: pick fields for those actions.
- methods: ask for what that field does, and leave impersonation out.

## How to get to it (user POV)

- `/range`, or a task whose name is an artifact ("a deck", "a report", "a fix").
- The user wants several kinds of expertise on one job.

## Driving it with the DeepStack skills

Preconditions: the task stated as the user gave it.

- Open [principle-nouns-to-verbs](../../../principle-nouns-to-verbs/SKILL.md). Result: a verb sentence for the job.
- Open [principle-assemble-the-crew](../../../principle-assemble-the-crew/SKILL.md). Result: a list of fields and the method each one runs.
- Open [principle-methods-leave-impersonation-out](../../../principle-methods-leave-impersonation-out/SKILL.md). Result: the worker does the method.

## Gotchas

- Asking the worker to sound like a specialist changes the transcript and leaves the method untouched.
- Range needs a machine that can install tools and reach the data.

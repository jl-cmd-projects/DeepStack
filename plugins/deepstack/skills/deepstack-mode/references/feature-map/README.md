# DeepStack feature map

This directory maps each kind of ambition to the skill that owns it. Read this index, then the feature file.

## Features

- [Altitude](altitude.md) aims at the outcome above the task.
- [Depth](depth.md) does the task the way a top person in the field would.
- [Range](range.md) brings in the fields the noun was hiding.
- [Self-efficacy](self-efficacy.md) sets the stance that makes a hard goal attemptable.

## Driving conventions

- Start from [deepstack-mode](../../SKILL.md).
- Open the principle leaf the feature names before applying it.
- A done claim uses [the trust card](../trust-card.md) and an outside judge.

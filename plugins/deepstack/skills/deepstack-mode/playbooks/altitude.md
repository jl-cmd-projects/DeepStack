# Altitude

1. Name the outcome the task is a guess at. Write that outcome in one sentence.
2. Hand the worker the raw material you can reach. Ask what changed, why, and what to do.
3. Ask for the few decisions that matter. Each one carries the case for it and the case against it.
4. Ask for a mechanism that serves the outcome. Using records you already have, show the new way would have surfaced the problem earlier. Try the new way next to the old way for one cycle.
5. If people will meet about this work, stay on altitude. A creative piece with no later decision moves to the depth playbook.
6. Before a person leaves the loop, open the durable-loop playbook.

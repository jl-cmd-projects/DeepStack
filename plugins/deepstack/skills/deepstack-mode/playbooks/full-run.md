# Full run

Every first task runs this playbook. It bakes each axis into the plan, then does the work.

1. Write the three lines and the four answers in `references/intake.md` before any plan.
2. Set the stance with `playbooks/self-efficacy.md`: a specific hard goal, a seen success when one exists, and room to miss.
3. Raise the task with `playbooks/altitude.md`. Name the outcome above the task in one sentence.
4. Deepen the method with `playbooks/depth.md`. Name the field's instruments and the raw source.
5. Widen the crew with `playbooks/range.md`. Turn each noun into its verb and list the fields that do that work.
6. Name the grader with `playbooks/outside-judge.md` before the work starts.
7. Put the outcome, the hard goal, the instruments, the crew, and the judge in the todo list. Then do the work.
8. A done claim carries the seven lines in `references/trust-card.md`.

An axis that adds nothing to this task stays in the todo list with `skip: <reason>`.

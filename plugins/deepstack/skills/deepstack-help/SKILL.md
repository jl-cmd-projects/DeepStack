# DeepStack help

Answer the question and link the file the answer came from. For a help question, do not start the work.

A message that asks for the work itself is not a help question. Read [deepstack-mode](../deepstack-mode/SKILL.md) and do the work under it.

DeepStack does its work in one skill, `deepstack-mode`. A first task runs [the full run](../deepstack-mode/playbooks/full-run.md), which covers every axis below.

| The user wants to | Playbook |
|---|---|
| Raise any first task and prove it | [full run](../deepstack-mode/playbooks/full-run.md) |
| Aim at the outcome above the task | [altitude](../deepstack-mode/playbooks/altitude.md) |
| Do the task the way a top person in the field would | [depth](../deepstack-mode/playbooks/depth.md) |
| Bring in fields the noun was hiding | [range](../deepstack-mode/playbooks/range.md) |
| Require the field's instruments | [instruments](../deepstack-mode/playbooks/instruments.md) |
| Set a specific hard target | [unreasonable goal](../deepstack-mode/playbooks/unreasonable-goal.md) |
| Reproduce a belief from raw material | [raw check](../deepstack-mode/playbooks/raw-check.md) |
| Find a signal that predicts on unseen material | [new knowledge](../deepstack-mode/playbooks/new-knowledge.md) |
| Name a judge that is not the worker | [outside judge](../deepstack-mode/playbooks/outside-judge.md) |

Pick models and the session hook with [setup-deepstack](../setup-deepstack/SKILL.md).

The article citation is in [source](../deepstack-mode/references/source.md).

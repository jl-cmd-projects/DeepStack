# DeepStack help

Answer the question and link the file the answer came from. For a help question, do not start the work.

A message that asks for the work itself is not a help question. Read [deepstack-mode](../deepstack-mode/SKILL.md) and do the work under it.

| The user wants to | Skill |
|---|---|
| Raise any first task and prove it | [deepstack-mode](../deepstack-mode/SKILL.md) |
| Aim at the outcome above the task | [altitude](../altitude/SKILL.md) |
| Do the task the way a top person in the field would | [depth](../depth/SKILL.md) |
| Bring in fields the noun was hiding | [range](../range/SKILL.md) |
| Require the field's instruments | [instruments](../instruments/SKILL.md) |
| Set a specific hard target | [unreasonable-goal](../unreasonable-goal/SKILL.md) |
| Reproduce a belief from raw material | [raw-check](../raw-check/SKILL.md) |
| Find a signal that predicts on unseen material | [new-knowledge](../new-knowledge/SKILL.md) |
| Name a judge that is not the worker | [outside-judge](../outside-judge/SKILL.md) |
| Pick models and the session hook | [setup-deepstack](../setup-deepstack/SKILL.md) |
